# 🤝 Contributing to DSAquest

Thank you for your interest in contributing! This guide will help you get started.

---

## 📌 Before You Start

- Check the [Issues](../../issues) tab for open tasks
- Look for issues labeled `good-first-issue` if you're new
- Comment on the issue you want to work on and wait for it to be assigned

---

## 🛠️ How to Contribute

### 1. Fork the Repository
Click the **Fork** button on the top right of this page.

### 2. Clone Your Fork
```bash
git clone https://github.com/SG170/dsaquest.git
cd dsaquest
```

### 3. Create a New Branch
```bash
git checkout -b feature/your-feature-name
```
Examples:
- `feature/add-arrays-problems`
- `fix/progress-tracker-bug`
- `docs/update-readme`

### 4. Make Your Changes
Write clean, well-commented code.

### 5. Commit Your Changes
```bash
git add .
git commit -m "feat: add curated problems for Arrays topic"
```

### 6. Push and Create a Pull Request
```bash
git push origin feature/your-feature-name
```
Then go to GitHub and click **New Pull Request**.

---

## ✅ Pull Request Checklist

Before submitting, make sure:
- [ ] Your branch is up to date with `main`
- [ ] Your code runs without errors
- [ ] You've described what your PR does in the description
- [ ] You've linked the related issue (e.g. `Closes #12`)

---

## 🏷️ Issue Labels

| Label | Meaning |
|---|---|
| `good-first-issue` | Great for newcomers |
| `help-wanted` | Open for anyone to pick up |
| `bug` | Something is broken |
| `enhancement` | New feature or improvement |
| `documentation` | Docs related |

---

## 💬 Need Help?

Feel free to comment on the issue or reach out to the project admin.
